# proyecto-AeroGo

Proyecto desarrollado para el curso de **Programación Orientada a Objetos** de la **Universidad Fidelitas**.

## Descripción

AeroGo es un proyecto universitario implementado en Java como parte del curso de Programación Orientada a Objetos (POO). El sistema simula la gestión de vuelos y reservas de una aerolínea, aplicando los principios fundamentales de la POO como herencia, encapsulamiento y polimorfismo.
